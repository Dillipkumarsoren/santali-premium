# Santali Premium APK - Landing Page

A professional, mobile-friendly landing page for the **Santali Premium APK** application.  
Designed with a clean, modern interface inspired by the Flash Light app, featuring an animated logo and a responsive layout that works beautifully on all devices.

![Santali Premium Preview](https://via.placeholder.com/800x400?text=Santali+Premium+Landing+Page)

---

## 🚀 Features

- **Fully Responsive** – Optimized for mobile, tablet, and desktop.
- **Animated Logo** – Floating crown with a subtle glow effect.
- **Hero Section** – Bold app name, tagline, and feature badge.
- **Feature Grid** – Showcases 6 key premium features.
- **About Section** – App description with key highlights.
- **Developer Info** – Displays developer name, email, and phone.
- **FAQ Section** – Answers common user questions.
- **Legal Pages** – Direct links to About Us, Contact Us, Disclaimer, Privacy Policy, and Terms & Conditions.
- **Font Awesome Icons** – Clean, scalable vector icons throughout.
- **Single HTML File** – No external dependencies (except Font Awesome CDN).
